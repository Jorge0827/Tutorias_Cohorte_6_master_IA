# Guía docente — escribir los `.py`, luego probar en el notebook

**No** uses el notebook para generar archivos. El código se **tipea** en el editor.

1. Abres `frontend/cliente_api.py` y lo escribes con ellos (httpx).
2. Abres `frontend/app.py` y lo escribes (Streamlit: widgets + spinner/error/success).
3. Uvicorn arriba.
4. Notebook: celdas que **importan** lo que acaban de guardar.
5. `streamlit run frontend/app.py`.

El texto que ya está en esos dos `.py` es el **guion** para ir escribiendo (o dejarlo y recorrerlo línea a línea). El back y los joblib ya estaban.
